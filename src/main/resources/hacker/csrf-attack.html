Ein Cocktail für dich!

Du bist bereits im guten Server angemeldet? Sichere dir jetzt deinen Cocktail.

Was wird vorgeführt?

Die Seite versucht, die persönliche Notiz des angemeldeten Benutzers zu überschreiben. Die Notiz enthält einen Stored-XSS-Nachweis. Sobald der Admin sie als HTML öffnet, meldet das Skript seine Ausführung an diesen Hacker-Server. Es werden keine Passwörter, Sitzungscookies oder Tokens gesammelt.
